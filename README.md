# venice-biennale-2026

Photos and videos from the 61st Venice Biennale (*In Minor Keys* and the national pavilions), grouped by artist with a short note on each work.

**Live site:** https://jmen.github.io/venice-biennale-2026/

- `index.html` – the gallery (a single static page, no build step)
- `thumbs/` – grid previews
- `photos/` – web-sized photos (metadata and location data removed)
- `videos/` – compressed MP4 clips

All artworks © the artists.
